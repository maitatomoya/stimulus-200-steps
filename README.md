# Stimulus 200 Steps

Stimulus（Hotwire）を基礎から250ステップで学べる学習Webサービス。
各ステップは「解説→課題→コード編集→実行→プレビュー→自動判定」を1ページで完結できる。

## 特徴

- 25章×10ステップ=250ステップのカリキュラム（DOM基礎からコントローラ・ターゲット・バリュー・アウトレット・実践コンポーネント、よくあるエラー50選まで）
- コードはブラウザ内のサンドボックスiframeで実行され、**実際に触って動作を確認できるプレビュー**付き
- 各ステップに自動判定（クリック・入力を自動で行いDOMの状態を検証）
- 1から書かせず、例コードの部分修正・穴埋め・不具合の修正を中心とした課題設計
- ヒント（段階表示）、模範解答、進捗のlocalStorage保存

## 必要環境

- Node.js 18以上（依存パッケージなし。npm install不要）
- インターネット接続（Stimulus 3.2.2とCodeMirrorをCDNから読み込むため）

## 使い方

```bash
git clone https://github.com/MaitaTomoya/stimulus-200-steps.git
cd stimulus-200-steps
node server.js
```

起動するとターミナルにURLが表示されるので、ブラウザで開く（デフォルトは http://localhost:3943 ）。
ポートは環境変数PORTで変更できる。

```bash
PORT=8080 node server.js
```

## 教材の検証

```bash
node scripts/validate.js
```

全ステップの模範解答＋自動判定の一括検証は、サーバー起動後に「表示されたURL + /test-runner.html」を開く。
